# 호텔 예약 프로그램 (C)

2021년에 C언어를 처음 배우면서 1주일 동안 만든 콘솔 프로그램이다.
배운 걸 하나로 묶어서 "진짜 쓰는 것 같은" 프로그램을 만들어 보고 싶었고, 그게 호텔 예약이었다.

지금 보면 고칠 게 많은 코드다. 그래서 고칠 점도 아래에 같이 적어 뒀다.

<br>

## 기능

- **로그인**: 아이디와 비밀번호를 입력해서 들어간다. (20자 이내)
- **객실 현황**: 1층부터 9층까지, 층마다 9개씩 총 81개 객실을 표로 보여 준다.
  - □ 예약 가능 / ■ 예약 불가(내가 예약한 방)
- **예약**: 방 번호를 입력하고, 비밀번호를 한 번 더 확인한 뒤 예약한다. 최대 3개까지.
- **정산**: 예약이 끝나면 예약한 방과 방별 요금, 총 금액을 보여 준다.

### 요금

| 층 | 요금 |
|---|---|
| 1 ~ 3층 | 60 $ |
| 4 ~ 6층 | 120 $ |
| 7 ~ 9층 | 180 $ |

## 실행 방법

Windows 전용이다. `windows.h`의 `Sleep()`이랑 `system("cls")`, `system("color ...")` 같은 콘솔 명령을 쓰기 때문이다.

1. Windows에서 C 컴파일러(Dev-C++, Visual Studio, MinGW gcc 등)로 연다.
2. 컴파일하고 실행한다.

```bash
gcc "호텔예약 프로그램.c" -o hotel.exe
```

> 소스 파일은 **EUC-KR(CP949)** 로 저장돼 있다. UTF-8로 열면 한글이 깨져 보이니까 인코딩을 EUC-KR로 맞춰서 열면 된다.

<br>

## 코드 구조

| 함수 | 하는 일 |
|---|---|

## 알려진 문제

처음 C를 배울 때 만든 거라 지금 다시 보니 버그가 있다. 일부러 안 숨기고 적어 둔다.

1. **이미 예약한 방 검사가 잘못돼 있다** (121번째 줄)
   ```c
   if(roomnum == roomnum1||roomnum2||roomnum3)
   ```
   연산자 우선순위 때문에 `(roomnum == roomnum1) || roomnum2 || roomnum3`으로 계산된다.
   방을 하나라도 예약하면 다른 방을 골라도 항상 "이미 예약한 방"이 된다.
   → `roomnum == roomnum1 || roomnum == roomnum2 || roomnum == roomnum3`으로 써야 한다.

2. **크기 없는 배열** `char pwok[];`
   전역에서 크기 없이 선언하면 사실상 1칸짜리 배열이 된다. 비밀번호를 입력하면 배열 밖을 덮어쓴다.
   → `char pwok[21];`처럼 크기를 정해야 한다.

3. **입력 길이를 미리 막지 않는다**
   `id[20]`, `password[20]`에 `scanf("%s")`로 받은 다음에 길이를 검사한다. 이미 넘친 뒤에 검사하는 거라 의미가 없다.
   문자열 끝 `\0` 자리까지 생각하면 21칸이 필요하다.
   → `scanf("%20s", id)`처럼 입력할 때 길이를 제한해야 한다.

4. **객실은 81개인데 배열은 80칸**
   9층 × 9개 = 81개인데 `allroom[80]`으로 선언했다. 마지막 방을 저장할 때 범위를 1칸 넘는다.

5. **함수끼리 계속 다시 부르는 구조**
   `start()`가 자기 자신을 부르고, `hotelmain()`과 `hotelchange()`가 서로를 부른다.
   오래 쓰면 호출이 계속 쌓여서 스택이 넘칠 수 있다.

6. **`scanf("%c")`가 줄바꿈을 먹는다**
   "방을 더 예약하시겠습니까?"에서 앞에 남은 줄바꿈을 바로 읽어 버린다. `scanf(" %c")`처럼 앞에 공백을 넣어야 한다.
   그리고 `case 'y':` 뒤에 `break`가 없어서 `case 'n'`까지 이어서 실행된다.

7. **컴파일 경고**
   함수 원형 선언 없이 먼저 호출했고, `int` 함수인데 값을 안 돌려주는 곳이 많다. `getch()`를 쓰는데 `conio.h`도 안 넣었다.

## 다시 만든다면

- 객실을 구조체 배열로 관리한다.
  ```c
  struct Room { int number; int reserved; int price; };
  ```
- 재귀 대신 `while` 반복문으로 메뉴를 돈다.
- 입력 길이를 제한하고, 잘못된 입력을 처리한다.
- 예약 내역을 파일에 저장해서 프로그램을 다시 켜도 남게 한다.
- 요금은 `room / 100`으로 층을 구해서 층별 요금표에서 가져온다.
- 화면 출력이랑 예약 로직을 함수로 나눈다.

## 배운 점

변수, 조건문, 반복문, 배열, 함수를 처음 하나로 엮어 본 프로젝트다.
